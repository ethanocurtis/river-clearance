Every NOAA NWPS gauge found along this stretch, St. Paul to St. Louis — not just the ones assigned to a bridge above. Bridge clearance is computed from each bridge's own assigned gauge (see the Gauge column in the list above); this is the full picture of river stage along the route.

Edits save directly to this server's copy of the data — live on the site immediately. If the server has auto-push configured, each save also commits and pushes that file to GitHub (the status message below each Save button says "Pushed to GitHub," or explains why not if it failed). If auto-push isn't configured, saves stay local only; run git add -A && git commit && git push on the VM to sync GitHub manually.

Gauges (docs/data/gauges.json)

Data covers the Upper Mississippi River from St. Louis, MO to St. Paul, MN — 42 bridges and every NOAA NWPS gauge found along the route (32 gauges). Live stage from NOAA NWPS / USGS when reachable; a stale cached reading is labeled as such; if none is available the bridge or gauge shows "Stage unavailable" rather than a guessed number. On the map, bridge pins are colored by status and gauges are plain blue dots. Report a data issue on GitHub ↗
