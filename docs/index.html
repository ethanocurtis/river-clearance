Every NOAA NWPS gauge found along this stretch, St. Paul to St. Louis — not just the ones assigned to a bridge above. Bridge clearance is computed from each bridge's own assigned gauge (see the Gauge column in the list above); this is the full picture of river stage along the route.

Seed data covers Dubuque, IA to St. Louis, MO on the Upper Mississippi River, plus every NOAA NWPS gauge found from St. Paul down to St. Louis. Live stage from NOAA NWPS / USGS when reachable; a stale cached reading is labeled as such; if none is available the bridge or gauge shows "Stage unavailable" rather than a guessed number. On the map, bridge pins are colored by status and gauges are plain blue dots. See README for how to add or correct bridges/gauges.
